# Mobile navigation checklist (iPhone)

Open https://dtam27.github.io/portfolio/ on your phone and verify:

- [ ] Header menu opens/closes and links jump to the right sections
- [ ] Hero CTAs are easy to tap (about thumb-size)
- [ ] Projects stack in one column without horizontal scroll
- [ ] Text is readable without zooming
- [ ] Footer email / GitHub / LinkedIn are tappable
- [ ] No content hidden under the notch or home indicator
